# Mechanic Kit（机械设备管理服务）

## 概述

Mechanic Kit 是机械体设备控制器提供的 API 集合，从 **API version 20** 起可用。它提供完整的三方机械体设备配件集成方案，通过 `mechanicManager` 模块实现设备连接管理、目标追踪和状态监控，支持精准控制，满足手机与云台等设备间的交互需求，帮助开发者构建高质量的设备交互应用。

## 核心能力

| 能力分类 | 功能 | 描述 |
|---------|------|------|
| 设备连接管理 | 设备发现 | 获取当前连接的机械体设备列表，支持云台等多种机械体设备类型 |
| 设备连接管理 | 连接状态监听 | 实时监听设备连接和断开状态变化 |
| 设备连接管理 | 设备信息查询 | 获取设备 ID、名称、类型等基本信息 |
| 目标跟踪控制 | 摄像头跟踪开关 | 启用或禁用摄像头目标跟踪功能 |
| 目标跟踪控制 | 跟踪布局设置 | 支持默认、左侧、中间、右侧四种跟踪布局模式 |
| 目标跟踪控制 | 跟踪状态监听 | 监听用户操作和布局变化等跟踪事件 |
| 设备状态监控 | 当前角度查询 | 实时获取设备在三个轴向的当前角度 |
| 设备状态监控 | 旋转限制查询 | 获取设备在各轴向的最大旋转范围 |
| 设备状态监控 | 旋转轴状态监听 | 监听各旋转轴的启用状态和限制情况 |
| 设备状态监控 | 运动参数查询 | 获取最大旋转速度和连续旋转时间 |

## 典型应用场景

1. **物体跟踪**：通过机械体设备实现人脸跟踪和物体追踪，提升拍摄质量
2. **拍摄控制**：手机作为控制终端，操控云台等机械体设备进行精准的角度调整和运动轨迹控制

## 运作机制

目标跟踪链路：

```
相机驱动（人脸检测）
    ↓ 上报人脸位置
相机服务（结合人脸位置和相机参数）
    ↓ 上报目标信息
机械体控制服务（转换为转动指令）
    ↓ 指令下发
蓝牙服务 → 机械体设备执行转动
```

应用侧通过 Mechanic Kit 开放接口控制目标跟踪功能的开关与布局。

## 约束与限制

| 项目 | 说明 |
|------|------|
| 机械体设备 | 必须符合 Mechanic Kit 协议标准（厂商已对外宣称支持） |
| 开发设备 | 目标跟踪需相机驱动具备人脸检测能力，支持上报符合 HDI 接口规范的 Metadata 数据 |
| 设备连接 | 开发设备必须与机械体设备建立连接，确保通信链路正常 |
| 相机权限 | 前台应用需获得相机使用权限，用于目标追踪等视觉相关功能 |
| 系统权限 | 转动控制等高级功能需要系统应用权限 |
| 硬件限制 | 操作范围受限于机械体设备的运动限位 |
| 模拟器 | 不支持 |

## 开发指南

官方文档：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/mechanic-kit-intro

### 基础使用流程

```
1. 获取当前连接的机械体设备列表
2. 监听设备连接/断开状态
3. 查询设备信息（ID/名称/类型）与旋转限制
4. 启用摄像头目标跟踪，设置跟踪布局
5. 监听跟踪状态与旋转轴状态变化
6. 按需执行角度调整与运动控制
```
